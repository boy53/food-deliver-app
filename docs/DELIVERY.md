# Delivery Documentation

## Delivery Workflow
1. Restaurant marks order `READY_FOR_PICKUP`.
2. System broadcasts delivery request to nearby online riders.
3. Rider accepts delivery request (`RIDER_ACCEPTED`).
4. Rider arrives at restaurant and confirms pickup (`PICKED_UP`).
5. Rider navigates to customer location (`OUT_FOR_DELIVERY`).
6. Rider confirms delivery completion (`DELIVERED`).
